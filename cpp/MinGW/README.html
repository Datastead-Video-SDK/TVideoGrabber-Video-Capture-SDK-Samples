MinGW compilation test

C++ / MinGW

This is a very trivial compilation test:

  1. Copy TVideoGrabber.h and TVideoGrabber.cpp in this folder.
  2. Depending on whether you are using MinGW32 or MinGW64, copy the corresponding x86 or x64 TVideoGrabber.dll in this folder.
  3. Open the MinGW command prompt and go to this folder.
  4. Type make to build the executable.
