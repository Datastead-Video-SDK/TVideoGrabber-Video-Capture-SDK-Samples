VB6 demo projects

OCX install

Be sure to register the vidgrab_VB6.ocx component before using the VB6 demo projects:

Start -> Run -> RegSvr32 [path to the ocx]\vidgrab_VB6.ocx

E.g.:

RegSvr32 c:\vidgrab\VB6\vidgrab_VB6.ocx

Properties

Some of the properties included in the user guide are not published (their values are not stored, so they are not visible with the object explorer), however they exist and you can assign and read their values (e.g. VideoDevice, AudioInput, etc.).

Types

The types described in the user guide begin by Tx in the OCX. E.g. TPlaylist in the user guide is TxPlaylist in the OCX.

They are all listed, with their values and links to the online and offline documentation, in EnumeratedTypes.html located in the folder of the OCX.

OnFrameBitmap and OnFrameProgress2 events

These events pass as parameter:

  • a pointer to a TFrameInfo structure,
  • a pointer to a TFrameBitmapInfo structure.

These structures are declared in the VidGrabUtil.bas module included with the MainDemo project.

Look at the FrameBitmap and FrameProgress2 events of the MainDemo project for sample code.

Upgrading the demo projects

If the demo projects were already opened with an earlier version of the OCX, delete vidgrab_VB6.oca next to the OCX and re-register the new OCX before opening them. No GUID has to be edited in the .vbp or .frm files: the identifiers of vidgrab_VB6.ocx are permanent.
